# research-literature

Record query/source/date and inclusion scope. Read original sources for central claims. For each entry keep citation metadata, the supported statement, source location, limitations and conflicting evidence. Distinguish source claims from your synthesis. Search failure does not establish novelty. Return a compact map with retrievable references; keep full papers outside the coordinator context.

For proposed hypotheses, compare nearest related work, assumptions, mechanisms and known counterexamples. Separate attributed knowledge, rediscovery and proposed extension. Record the basis and date/scope of a candidate novelty assessment; do not issue a global novelty verdict from missing search hits or an LLM preference score.

For synthesis_planning, re-open the relevant primary sources and research important uncertainties afresh; the earlier evidence map is an input to verify. Follow the [planning verification contract](../research-design/references/planning-verification.md). Keep source artifacts retrievable with hashes and dates; a prior analyst's citation summary is not a primary source.

Use the role, study guidance, acceptance criteria and effective configuration supplied with the task. Load only the artifacts needed for the current question. Return a concise result with evidence references, performed checks, limitations and unresolved items using the harness result contract when dispatched by the harness. Keep durable evidence outside chat.

When an extension profile is supplied for scholarly tools, read [retrieval and bibliography guidance](references/retrieval-tools.md) for identifier/coverage rules and finite helper usage.
